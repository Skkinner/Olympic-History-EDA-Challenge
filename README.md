# 🏅 Olympic History — EDA Pair Challenge

## 📌 Project Overview

This project is a **pair programming challenge** focused on exploring 120 years of Olympic history using Python.

The challenge involves applying **Exploratory Data Analysis (EDA)** techniques to investigate athlete participation, medal distributions, missing data, and historical trends across the Summer and Winter Olympic Games.

The exercises progress through multiple difficulty levels, from basic data exploration to advanced data visualization.

## 🎯 Project Objectives

- Practice data cleaning and preprocessing.
- Identify and analyze missing values.
- Explore athlete demographics and participation.
- Analyze Olympic medal distributions.
- Visualize historical patterns and trends.
- Strengthen Python data analysis and visualization skills.
- Apply Pandas operations without relying on explicit `for` loops.

## 📊 Dataset

**Dataset:** 120 Years of Olympic History: Athletes and Results

**Source:** [Kaggle — Olympic History Dataset](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)

**File:** `athlete_events.csv`

The dataset contains historical Olympic records, including:

- Athlete ID and name
- Gender and age
- Height and weight
- Team and country
- Olympic year and season
- Host city
- Sport and event
- Medal type (Gold, Silver, Bronze)

## 🧩 Challenge Structure

### 🟢 Level 1 — Beginner

Basic data exploration and cleaning:

1. Identify missing values in each column.
2. Calculate the number of male and female records.
3. Explore Olympic host cities and their frequencies.
4. Detect and remove duplicate records.

### 🟡 Level 2 — Intermediate

Analyze Olympic participation:

1. Count athlete records for each Olympic year.
2. Identify the athlete with the highest number of recorded participations.

### 🔴 Level 3 — Advanced

Explore medal distributions:

1. Calculate the number of Gold, Silver, and Bronze medals awarded each year.

### 📈 Level 4 — Data Visualization

Transform analysis results into visualizations:

1. Visualize the number of gold medal records by host city.
2. Analyze the total missing values for each Olympic year.

### 🚀 Level 5 — Bonus Challenge

Analyze historical athlete participation:

1. Investigate how the number of unique athletes changed over time.
2. Compare Summer and Winter Olympic participation.
3. Use Pandas grouping operations and Seaborn visualization without explicit `for` loops.
